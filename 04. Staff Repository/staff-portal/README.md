# 👩‍🏫 Staff Portal — School ERP Ecosystem

Teacher-facing portal for daily attendance roster marking, class schedule tracking, and faculty escalations.

---

## 🌟 Key Features
- 📝 **1-Click Attendance Roster**: Mark classroom attendance with instant Present/Absent/Late toggle buttons, date selector, and batch submission.
- 📅 **Faculty Timetable Schedule**: View assigned teaching periods across classes and subjects for each day of the week.
- 👥 **Classroom Roster Compliance**: Track individual student attendance percentages and flag chronic absenteeism.
- 🤖 **Embedded XYZ AI Assistant**: Natural language voice and chat interface to query timetables or mark attendance conversationally.
