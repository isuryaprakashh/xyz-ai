# Ponytail Help & Quick Reference

## Levels
- `lite`: Build what is asked, name the lazier alternative in one line.
- `full` (default): YAGNI -> standard library -> native platform -> one line -> minimum code.
- `ultra`: Deletion before addition; challenges requirements before building.

## Bundled Skills & Commands
- `ponytail`: Switch ponytail mode or intensity level.
- `ponytail-review`: Review code changes / diff for over-engineering.
- `ponytail-audit`: Audit entire repository tree for over-engineering and cuttable lines.
- `ponytail-debt`: Scan and harvest `ponytail:` comments into a tracked ledger.
- `ponytail-gain`: Display benchmark efficiency metrics.
- `ponytail-help`: Display this reference card.
