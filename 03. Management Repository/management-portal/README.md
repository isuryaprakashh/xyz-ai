# 🏛️ Management Portal — School ERP Ecosystem

Executive portal for Principals and School Administrators to oversee school-wide analytics, manage user accounts (CRUD), manage timetables, and monitor security telemetry.

---

## 🌟 Key Features
- 📊 **School-Wide Analytics**: High-level attendance compliance metrics, class-by-class comparison charts, and low-attendance alerts.
- 👥 **Principal User Management (CRUD)**: Add, edit, and delete users across roles (Students, Parents, Teachers, Principals) with dynamic class and child assignments.
- 📅 **Master Timetable Management**: View and modify weekly period schedules for all classes (Class 1A through 5B).
- 🎫 **Escalation Ticket Queue**: Monitor parent callback requests, assign priorities, and log resolution notes.
- 🔒 **Immutable Security Audit Telemetry**: Inspect real-time audit logs, RBAC violations (`403 Forbidden`), and injection attempt alarms.
