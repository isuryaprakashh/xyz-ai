# 🎓 Student Portal — School ERP Ecosystem

Student-facing academic portal for viewing personal attendance, timetable schedules, and academic progress with embedded AI Copilot support.

---

## 🌟 Key Features
- 📊 **Personal Attendance Tracker**: Live attendance percentage gauge, total days present/absent, and streak counter.
- 📅 **Weekly Class Timetable**: Day-by-day class schedule with subject names, teacher names, and timings.
- 🤖 **Embedded XYZ AI Assistant**: Multimodal chat and voice assistant for natural language academic inquiries.
- 🔒 **Zero-Trust Security**: Student account isolation — write actions and cross-student data access are blocked.
